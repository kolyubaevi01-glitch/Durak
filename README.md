# Дурак Club — Telegram Mini App

Что нужно: бот в Telegram и любой хостинг с Node.js 18+ и https (Render, Railway, Fly и т.п.).

1. В Telegram откройте @BotFather → /newbot → получите токен.
2. Загрузите эту папку на хостинг. Сборка: `npm install`, запуск: `node server.js`.
3. Переменные окружения:
   - BOT_TOKEN — токен бота;
   - WEBAPP_URL — публичный https-адрес сервиса без `/` на конце.
4. Откройте бота → /start → «Играть». Кнопка «Играть» появится и в меню бота.

Проверка в браузере без Telegram: запустите с `DEV=1` и откройте `/#dev1` и `/#dev2` в двух вкладках.

Как устроено: `server.js` — сервер (раздаёт игру, хранит столы и рейтинг, проверяет подпись Telegram, запускает бота). `tg.js` — подключение игры к серверу и к Telegram. `index.html` — сама игра.
Друг приглашается ссылкой из экрана ожидания или кодом (код = ваш Telegram ID). Приглашение из списка друзей приходит сообщением от бота, если друг запускал бота.

Ограничения: данные хранятся в `data.json` (на бесплатных хостингах диск может сбрасываться); карты лежат в общем состоянии стола, поэтому честность держится на доверии, а не на проверке сервера.
